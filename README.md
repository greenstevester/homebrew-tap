# greenstevester/homebrew-tap

Homebrew tap for [AllTalk](https://github.com/greenstevester/alltalk) and other tools.

## AllTalk

```sh
brew install --cask greenstevester/tap/alltalk
```

AllTalk is signed and notarized, so it opens with a normal double-click. It also needs a
local llama.cpp server and the Voxtral model — run `brew install llama.cpp` and download
the model (see the [main README](https://github.com/greenstevester/alltalk)).
